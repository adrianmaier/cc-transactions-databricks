## Data Source

This project uses the publicly available Credit Card Transactions dataset published on Kaggle by Erik Altman and collaborators.

Source: https://www.kaggle.com/datasets/ealtman2019/credit-card-transactions

The dataset was used as the source data for the Databricks Bronze → Silver → Gold pipeline. The raw transaction data is not included in this repository. The repository contains the project code, documentation, derived analytical data products, Power BI report, and report screenshots.

Please refer to the original Kaggle dataset page for the applicable license and terms of use.
